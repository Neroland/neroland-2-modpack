# Neroland 2

The official repository and issue tracker for **Neroland 2** — a curated sci-fi
modpack for **Minecraft 26.3** on **NeoForge**.

Built around the Neroland mods — industrialise, automate, and blast off to alien
worlds — rounded out with a small, hand-picked set of community mods for the
quality-of-life and exploration essentials. Curated, not kitchen-sink.

## Getting the pack

- **CurseForge:** _link once published_

Easiest route is the CurseForge app: search for **Neroland 2**,
click **Install**, then **Play**.

**Requirements:** Minecraft 26.3 · NeoForge · 6 GB RAM allocated recommended ·
a modern quad-core CPU.

## Hosting a dedicated server

Download `Neroland-2-<version>-server.zip` from the matching [GitHub release](https://github.com/Neroland/neroland-2-modpack/releases).
Extract it into a new directory, then run `.\startserver.bat` on Windows or
`bash startserver.sh` on Linux. The launcher uses Java 25 to install the pinned
mods and NeoForge. Use the same Neroland 2 version on the client.

## What's inside

**Neroland mods** — Neroland Core, Nerospace, NeroTech, NeroPower, NeroLogistics,
NeroLink, NeroAgriculture, NeroDecor, NeroQuests, NeroEconomy, NeroColonies,
NeroEvents and NeroSecurity. They share Core's materials, energy
and progression, so there are no clashing recipes or duplicate ores between them.
Mapping comes from **NeroMaps**, the family's own minimap and world map, which joins
the pack with its first CurseForge release.

**Community mods** — JEI, Jade, Waystones, Distant Horizons,
Nature's Compass, AppleSkin, Energized Power and a handful of quality-of-life and
performance additions.

The full, exact mod list for any given release is in the pack itself and in
[CHANGELOG.md](CHANGELOG.md).

## Reporting issues

Please use the issue templates. Include:

- your **pack version**
- a **crash log or latest.log** uploaded to [mclo.gs](https://mclo.gs)
- clear **reproduction steps**

Crashes and bugs in an individual mod are usually best reported to that mod's own
issue tracker — but if you're not sure, open it here and we'll route it.
